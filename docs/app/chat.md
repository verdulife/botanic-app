# Module — Chat

## Purpose

Permitir comunicación directa entre usuarios, inicialmente vinculada al marketplace P2P.

## MVP views

- lista de conversaciones;
- conversación individual;
- iniciar nueva conversación;
- compartir publicación dentro de una conversación.

## Core flows

### From listing

Detalle de publicación -> Contactar -> conversación.

### From chat

Conversación -> referencia a publicación compartida -> detalle de publicación.

## Wireframe behavior

Representar mensajes, estados de conversación y acciones de envío con datos simulados. No implementar mensajería en tiempo real todavía.
