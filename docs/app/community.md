# Module — Community

## Purpose

Crear una comunidad de preguntas y respuestas sobre plantas, jardinería y huerto.

## Views

- listado principal;
- búsqueda opcional;
- crear publicación/pregunta;
- detalle del hilo;
- respuesta;
- mis publicaciones.

## Core flow

Usuario -> Comunidad -> nueva pregunta -> hilo -> respuestas.

Una publicación de comunidad debe poder abrirse directamente desde una notificación.

## Scope

El MVP debe centrarse en texto y estructura básica de preguntas/respuestas. Moderación avanzada y capacidades sociales adicionales quedan fuera del core.
