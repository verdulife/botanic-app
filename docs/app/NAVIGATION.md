# Botanic — Navigation

## Navegación principal

La aplicación contempla cuatro destinos principales:

1. `Marketplace P2P`
2. `Deseos`
3. `Comunidad`
4. `Botanic Market`

La forma visual concreta de presentarlos queda abierta al desarrollo. La documentación solo fija que deben ser accesibles desde la navegación principal.

## Acciones globales

Además de la navegación principal, deben existir accesos contextuales a:

- notificaciones;
- perfil / cuenta;
- ajustes;
- crear publicación P2P;
- búsqueda;
- chat cuando existan conversaciones.

## Reglas

- El estado de navegación debe mantenerse al cambiar entre vistas.
- Las rutas profundas deben poder abrirse directamente.
- Una publicación P2P puede originar un flujo hacia chat.
- Una coincidencia de deseo puede originar un flujo hacia el detalle de una publicación.
- Una notificación puede llevar directamente al recurso relacionado.
- Un hilo de comunidad debe poder abrirse directamente y volver al listado.
