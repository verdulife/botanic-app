## MVP / MPL

El producto puede incluir más pantallas que funcionalidades realmente conectadas. El objetivo es que la experiencia completa sea visible y navegable desde el primer wireframe.

## Futuro

Se considera fuera del core inicial cualquier evolución profesional de Botanic Market, automatizaciones avanzadas y capacidades no necesarias para demostrar el valor principal.
