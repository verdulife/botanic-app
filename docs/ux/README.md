# Botanic — Documentación UX

> **REGLA PARA EL AGENTE — CARGA CONDICIONAL**
>
> Esta carpeta contiene decisiones de UX/UI tomadas específicamente para la experiencia móvil de Botanic.
> **Lee estos documentos únicamente cuando el usuario pida explícitamente diseñar, revisar, modificar o implementar algo relacionado con UX/UI, jerarquía de navegación, patrones de interacción o presentación del feed.**
>
> **No cargues esta carpeta como contexto general del proyecto** para implementaciones ordinarias de funcionalidades.

## Alcance

Esta carpeta contiene únicamente las decisiones de UX establecidas en esta conversación:

- Simplificación de la navegación móvil.
- Gestión contextual de Deseos / alertas.
- Área unificada de "Mi Botanic" para acciones personales.
- Modos de vista del P2P: Lista, Mapa y Match.
- Estructura del feed y bloques horizontales.
- Prompts contextuales para el registro.
- Principios para permitir explorar sin cuenta y fomentar el registro.
- Relaciones UX entre exploración, acciones y gestión personal.

## Archivos

- `UX_GUIDELINES.md` — principios y decisiones UX consolidados.
- `NAVIGATION_UX.md` — jerarquía de navegación móvil y modelo de interacción.
- `FEED_UX.md` — estructura del feed P2P, modos de vista, módulos contextuales y prompts de registro.

## Fuente de verdad

Estos documentos representan únicamente decisiones de UX. No sustituyen:

- definición de rutas,
- especificaciones de funcionalidades,
- arquitectura de la aplicación,
- implementación técnica,
- sistema visual definitivo.

Cuando exista un conflicto, el agente no debe reinterpretar silenciosamente estas reglas. Debe identificar el conflicto y utilizar como fuente de verdad la documentación del proyecto que sea más específica y actual.
